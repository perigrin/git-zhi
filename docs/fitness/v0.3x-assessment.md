## v0.4 Callouts (ranked by impact)

1. **`git zhi issue add --parallel`** — Every batch-add chain needs
   dependency correction. This was the most time-consuming M2 fix.
   Adding a `--parallel` flag would eliminate the structural correction step.

2. **Refinement should auto-scan PRD design principles** — The
   "self-announcing" principle wasn't propagated to per-issue AC.
   Refinement should parse the design principles section and add
   relevant AC items automatically.

3. **Alignment should auto-diff PRD headers against issue titles** —
   Would have caught the marketplace gap mechanically instead of requiring
   manual section-by-section comparison.

4. **Assess as standalone project health check** — detect-version conflict
   resolution and dist.ini detection are useful outside the fitness
   assessment context. Could be a `git zhi health` command.

5. **Anthropologist for semantic cluster quality** — The historian produces
   clusters but can't evaluate whether they represent coherent work units.
   Highest value for repos with low ticket-ref coverage (Blawd).

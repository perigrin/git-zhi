## Prerequisites

Before Milestone 0 begins:

1. git-zhi v0.3.1 binary on `$PATH` (`git zhi version` succeeds)
2. Crochet plugin installed (`/crochet:install` available)
3. Superpowers plugin installed
4. Episodic memory plugin installed
5. Validation repos cloned:
   - `~/dev/chalk` (already present)
   - `~/dev/pvm` (already present)
   - `gh repo clone perigrin/blawd ~/dev/blawd`
   - `gh repo clone perigrin/Iterum ~/dev/iterum`
   - `gh repo clone Tamarou/Registry ~/dev/registry`
6. `perl-development-plugin` repo created:
   - `gh repo create perigrin/perl-development-plugin --public`
   - Clone locally, initialize directory structure from plugin PRD

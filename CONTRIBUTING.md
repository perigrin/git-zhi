# Contributing

Start with [CONTRIBUTORS.md](CONTRIBUTORS.md) — build commands, architecture,
package structure, invariants and conventions all live there. This file is the
index to everything else.

## Short Links to Important Resources

- [Contributing guides](docs/contributing) — coding conventions and development workflow
- [Decisions](docs/decisions) — architecture decision records (ADRs)
- [Plans](docs/plans) — implementation plans and design documents
- [PRD](docs/PRD) — product requirements by version (v0.1 through v0.5)
- [Fitness](docs/fitness) — release observations and smoke-test records
- [Superpowers](docs/superpowers) — plans written against the superpowers workflow

`docs/guides`, `docs/architecture` and `docs/reference` exist as empty
directories and are deliberately not linked here. Git does not track an empty
directory, so a link to one is dead on a fresh clone — add the link in the same
commit as the first file that lives there.
